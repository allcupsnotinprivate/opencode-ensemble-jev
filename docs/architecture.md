# Поток решения

1. При `team_tasks_add` Lead получает начальную оценку первых `maxAgents` задач. Остальные оцениваются по запросу или при spawn. Lead получает инструкции через `session.hook("context")`. Изменения требований сообщаются вызовом `jev_route_task` с `trigger:"phase"`.
2. Обёртка executor `team_spawn` через `tool.transform` проверяет допуск до обращения к Jev, в том числе в Code Mode. Локальная классификация строит компактный `state`. Jev оценивает tier, сложность, планирование, изоляцию, параллелизм и review одной пачкой независимых вопросов. ID моделей не являются вариантами Jev.
3. Строгий парсер проверяет тип каждого запрошенного ответа, известность выбранной категории, диапазоны score и вероятностей. Используется provider confidence, а не придуманное объяснение. Повтор допустим только для transport/429/5xx в пределах общего дедлайна. Одинаковые наборы признаков и стадия в одной сессии разделяют promise с TTL 60 секунд; это относится и к сбоям.
4. Список кандидатов — пересечение пользовательского списка и `ctx.model.list().data`. Поиск идёт по порядку внутри tier, затем к менее мощным доступным tier, затем к более мощным до потолка бюджета. Модель пользователя проходит те же ограничения. Для критичных изменений локальный минимум review — deep, если дополнительная проверка включена.
5. Обёртка публичного executor повторно проверяет модель, запрашивает `EnsembleRpc.teamContext`, проверяет лимит и передаёт исходному executor `model`, `worktree`, `plan_approval`. Слот защищён от одновременных вызовов одного Lead. `parallel` — рекомендация о декомпозиции; `maxAgents` — ограничение запуска. Никакого доступа к хранилищу Ensemble.
6. При переходе в дочерний checkout в metadata сессии сохраняются только производные признаки задачи. Ошибки сравниваются по локальному хешу инструмента и аргументов, без передачи аргументов. Тактическая рекомендация действует на следующем шаге; повторная сигнатура и cooldown подавляют повтор. Платформенный retry не переопределяется. Watchdog Ensemble сам определяет stalled; маршрутизатор распознаёт его нотификацию при prompt admission. Этот конкретный путь зависит от формата сообщения Ensemble.
7. Успешный `team_tasks_complete` или структурированный отчёт `<status>completed</status>` через `team_message` инициирует дополнительный review. Уровень записывается в контекст Lead по ключу задачи. Это событие означает отчёт исполнителя, не подтверждение тестов. `team_results`, `team_shutdown` и `team_merge` исполняются Ensemble.

## Карта репозитория

```text
src/
  index.ts                 V2 entrypoint, каталог моделей, четыре инструмента
  config.ts                схема Zod, defaults, overlay
  jev/client.ts            OpenRouter transport, схемы, deadline/retry
  routing/policy.ts        локальные признаки, вопросы, минимумы review
  routing/model.ts         разрешённые модели, приоритет и потолок
  routing/strategic.ts     бюджет, кеш, стратегическое решение
  routing/tactical.ts      lease, сигнатуры ошибок, cooldown, эскалация
  ensemble.ts              admission, аудит результата, привязка checkout
  lifecycle.ts             задачи, ошибки, границы этапов, review → Lead
  review-outbox.ts         очередь доставки review в OpenCode storage, повтор после перезагрузки
  telemetry.ts             JSONL, буфер и счётчики
tests/
  router.test.ts           клиент, политики, конфиг, гонки, аудит
  live/run.ts              сквозной тест изолированного OpenCode CLI
  live/probe/index.ts      проверка мутации аргументов Code Mode
  live/decisions/index.ts  тестовая инъекция transport
  live/broken-worktree/    тестовая стратегия отказа
  live/openrouter.ts       ручной сетевой smoke
examples/                  opencode.json и ensemble-jev.json
docs/                      архитектура и протокол совместимости
.github/workflows/ci.yml   типы, unit, real-host и упаковка
```

`src/index.ts` экспортируется непосредственно как server part; runtime не зависит от Bun API. Тестовая подмена transport не настраивается через JSON. Политики не анализируют свободный текст ответа Jev. Все причины в журнале формируются кодом.
